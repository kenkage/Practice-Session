## 📖 About

**Practice Session** is a structured, topic-wise repository of Data Structures & Algorithms problems solved in **C#**. Each folder represents a core CS topic, containing well-commented solutions designed for clarity and learning.

Whether you're a beginner building fundamentals or someone preparing for technical interviews at top companies, this repository serves as a comprehensive reference.

### ✨ Highlights

- 🧩 **120+ problems** spanning 15 topic categories
- 📁 Clean, **topic-wise organization** for easy navigation
- 💡 Well-commented solutions with **clear logic and approach**
- 🎯 Covers **interview-favorite** and **competitive programming** problems
- 🔧 Built with **.NET 7.0** — modern, fast, and cross-platform

## 🚀 Getting Started

### Prerequisites

- [.NET SDK 7.0](https://dotnet.microsoft.com/en-us/download/dotnet/7.0) or later
- Any C# compatible IDE (Visual Studio, VS Code, Rider)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/kenkage/Practice-Session.git
   cd Practice-Session
   ```

2. **Restore dependencies**
   ```bash
   dotnet restore
   ```

3. **Build the project**
   ```bash
   dotnet build
   ```

4. **Run a solution**
   ```bash
   dotnet run --project test/test.csproj
   ```

## 💡 How to Use

1. **Browse by topic** — Navigate to the relevant folder for the concept you want to practice.
2. **Read the problem** — Each file contains a clear problem description in the comments.
3. **Study the solution** — Solutions include step-by-step logic with comments.
4. **Try it yourself** — Modify the `Main` method to test different inputs.
5. **Compare approaches** — Some problems include multiple approaches (brute force → optimized).

## 🤝 Contributing

Contributions are welcome! If you'd like to add new solutions or improve existing ones:

1. **Fork** the repository
2. **Create** a feature branch
   ```bash
   git checkout -b feature/add-new-solution
   ```
3. **Add** your solution in the appropriate topic folder
4. **Commit** your changes with a descriptive message
   ```bash
   git commit -m "Add: Two Sum solution using HashMap - Arrays"
   ```
5. **Push** to your branch and open a **Pull Request**

### Contribution Guidelines

- Follow existing code style and naming conventions
- Add comments explaining the approach and time/space complexity
- Place the solution in the correct topic folder
- Use meaningful file names (e.g., `TwoSum.cs`, `LRUCache.cs`)
